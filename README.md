## 🎯 Enfoque 
- Aprenderás a modelar datos con distintos modelos de redes complejas utilizando Python.
- **Enfoque en la investigación**: Lectura e implementación práctica de *papers* científicos a lo largo del curso.
- Utilizaremos librerías como:
  - `networkx`
  - `Py3Plex`
  - `Pymnet`
  - `Teneto`
  - `xgi`
- Consumo de APIs y análisis exploratorio de datos (EDA).
- Diversos modelos de redes complejas, detección de comunidades y simulaciones epidémicas.

## 📚 Contenido y Estructura del Curso

- **Notebooks (`.ipynb`)** con simulaciones, introducción a librerías y **análisis de datos**.

La estructura de carpetas está organizada por semanas y clases, siguiendo el formato `S#️⃣` en donde `#️⃣` es el número de semana en la que se impartió. Dentro de cada carpeta se encontrarán los códigos en Python así como bases de datos o *papers* necesarios para utilizar dichos códigos.

### Temario por Semanas:

* **S02:** APIs  `|||` Aspectos Básicos de Python y Numpy.
* **S03:** EDA con Pandas `|||` Introducción a [NetworkX](https://networkx.org/documentation/stable/reference/index.html).
* **S04:** Métricas en NetworkX  `|||` Redes aleatorias de Erdös-Rényi.
* **S05:** **Modelos de Redes:** Redes de Mundo pequeño `|||` Redes de Libre escala.
* **S06:** Percolación (Artículo de referencia) `|||` Algoritmo de Visibilidad para series de tiempo.
* **S07:** **Comunidades:** Algoritmo Louvain `|||` Infomap y Map Equation.
* **S08:** Discución de ([Bayesian stochastic blockmodeling](https://arxiv.org/pdf/1705.10225)) `|||` Introducción y métricas multicapa con [pymnet](https://mnets.github.io/pymnet/index.html).
* **S09:** Discución de ([Network Reconstruction via the minimum description length (MDL) principle](https://arxiv.org/pdf/2405.01015)) `|||` Bootstrapping y Caminatas aleatorias en Py3plex.
* **S10:** Discución de ([Graphs are maximally expressive for High Order Network interactions](https://arxiv.org/pdf/2602.16937)) `|||` Modelos epidemiológicos SIR e implementación en Py3plex.
* **S11:** Examen `|||` Redes temporales con Teneto y métricas temporales.
* **S12:** Sincronización de Kuramoto en complejos simpliciales. `|||` Temporal Communities through Trajectory Clustering (TCTC).
* **S13:** Algoritmo BallMapper `|||` Introducción a Redes de Orden Superior (HONs) con [XGI](https://xgi.readthedocs.io/en/latest/index.html).
* **S14:** Homología de persistencia: Discución de ([Identifying Key Genes in Cancer Networks Using Persistent Homology](https://www.nature.com/articles/s41598-025-87265-4)) `|||`
